## 2. In-Game Editor Navigation Workflow

1. **Accessing the Editor**:
   - Right-click a villager with an Editor Token or run `/mca editor`.
   - The left sidebar displays main categories: **[ Character ]**, **[ Profession ]**, **[ Inventory ]**, **[ Relationships ]**, etc.
2. **Selecting the Breast Subpage**:
   - Under **[ Character ]**, observe the horizontal subpage tabs at the top:
     `[ Body ] | [ Clothing Style ] | [ Hair Style ] | [ Eyes ] | [ Breast ]`
   - Click **[ Breast ]** to enter the dedicated customization screen.
3. **Navigating the 3 Sub-Categories**:
   - Beneath the tab bar, three toggle buttons switch active sub-categories:
     - **[ Size ]**: Independent Left and Right volume sliders (`0%` to `100%`).
     - **[ Position ]**: Horizontal ($X$), Vertical ($Y$), and Depth ($Z$) position sliders.
     - **[ Rotation ]**: Pitch ($X$), Yaw ($Y$), and Roll ($Z$) 3D Euler angle sliders.
4. **Toggling Symmetry Link Modes**:
   - **Slider Link Mode**: When `LINKED`, adjusting one slider automatically mirrors the value to the opposite side.
   - **Position Symmetry**: When `MIRRORED`, horizontal offsets ($X$) mirror inversely ($-X \leftrightarrow +X$), while vertical ($Y$) and depth ($Z$) sync symmetrically.
   - **Rotation Symmetry**: When `MIRRORED`, Yaw and Roll invert for symmetrical cleavage angling, while Pitch syncs identically.
   - **Back-Face Anchor**: Toggles real-time vertex clamping against the torso back wall.
5. **Real-Time 3D Viewport Synchrony**:
   - Any adjustment instantly updates the 3D villager preview model on the left viewport without requiring screen reload or world re-entry.

## 3. Mathematical Mapping Formulas

### Linear Volume Scaling Formula
Slider integer values $V_{\text{slider}} \in [0, 100]$ map linearly to model scale $S$:

$$S = \left(\frac{V_{\text{slider}}}{100}\right) \times 4.44$$

$$V_{\text{slider}} = \text{round}\left(\frac{S}{4.44} \times 100\right)$$

### Position Offset Formula
Position slider values $P_{\text{slider}} \in [-100, 100]$ map to local block translation units:

$$T = \frac{P_{\text{slider}}}{100.0} \quad (\text{blocks})$$

### Rotation Angle Formula
Euler rotation sliders map directly to degrees without conversion:

$$\theta_{\text{deg}} = R_{\text{slider}} \in [-90^\circ, +90^\circ]$$

$$\theta_{\text{rad}} = R_{\text{slider}} \times \frac{\pi}{180}$$

## 7. Developer & Mixin Hooks

### `VillagerEditorScreenMixin.java`
```java
@Inject(method = "addCharacterSubpageTabs", at = @At("HEAD"), cancellable = true)
private void onAddCharacterSubpageTabs(int y, String selectedPage, CallbackInfo ci) {
    int tabWidth = DATA_WIDTH / 5;
    addCharacterSubpageTab(width / 2, y, tabWidth, "body", selectedPage);
    addCharacterSubpageTab(width / 2 + tabWidth, y, tabWidth, "clothing_style", selectedPage);
    addCharacterSubpageTab(width / 2 + tabWidth * 2, y, tabWidth, "hair_style", selectedPage);
    addCharacterSubpageTab(width / 2 + tabWidth * 3, y, tabWidth, "eyes", selectedPage);

    // Injects 5th dedicated sub-tab: Breast
    ButtonWidget breastButton = this.addRenderableWidget(new ButtonWidget(
        width / 2 + tabWidth * 4, y, DATA_WIDTH - tabWidth * 4, 20,
        Component.literal("Breast"),
        b -> this.setPage("breast_addon")
    ));
    breastButton.active = !"breast_addon".equals(selectedPage);
    ci.cancel();
}
```

### Whitelisting C2S Packets (`VillagerEditorSyncRequestMixin.java`)
```java
@Mixin(value = VillagerEditorSyncRequest.class, remap = false)
public abstract class VillagerEditorSyncRequestMixin {
    @Inject(method = "isAllowedTopLevelKey", at = @At("HEAD"), cancellable = true, remap = false)
    private static void onIsAllowedTopLevelKey(String key, CallbackInfoReturnable<Boolean> cir) {
        if (key != null && key.startsWith("mca_inclusive_expressions:")) {
            cir.setReturnValue(true);
        }
    }
}
```
