## 2. In-Game Player & Administrator Workflow

### Setting Server GameRules via Chat
Server administrators can configure entity behavior globally using vanilla Brigadier commands:

```bash
# Force 3D breasts on all villagers globally (including male characters)
/gamerule mca_inclusive_expressions:force_all_breasted true

# Query the current status of force_all_breasted
/gamerule mca_inclusive_expressions:force_all_breasted

# Set the natural spawn chance of the Full-Chested trait to 20%
/gamerule mca_inclusive_expressions:full_chested_trait_chance 20

# Query the current full_chested_trait_chance
/gamerule mca_inclusive_expressions:full_chested_trait_chance
```

### Accessing Client Configuration via ModMenu
1. Press `Escape` and navigate to **Mods** (ModMenu).
2. Locate **MCA Inclusive Expressions** in the mod list and click the **Settings (⚙)** button.
3. If YACL v3 is installed, the configuration screen appears with real-time sliders for default scale multipliers, gender overrides, and a dedicated **Ko-fi Creator Support** button.

## 3. Probability Math & Sampling Equations

### Trait Spawn Probability
During male entity generation, the trait randomizer evaluates:

$$P(\text{Full-Chested}) = \frac{C_{\text{trait}}}{100} \quad \text{where } C_{\text{trait}} \in [0, 100]$$

If $C_{\text{trait}} \ge 100$, the trait is guaranteed ($P = 1.0$). If $C_{\text{trait}} = 0$, the trait will never generate naturally ($P = 0.0$).

In Java code (`TraitsMixin.java`):
```java
int chancePct = MCAInclusiveExpressionsAddon.getFullChestedTraitChance();
boolean shouldHave = (chancePct >= 100) || (chancePct > 0 && mob.getRandom().nextInt(100) < chancePct);
```

## 5. Registry & Codec Schema

GameRules are registered directly into Mojang's `BuiltInRegistries.GAME_RULE`:

```java
FORCE_ALL_BREASTED_RULE = Registry.register(
    BuiltInRegistries.GAME_RULE,
    "mca_inclusive_expressions:force_all_breasted",
    new GameRule<>(
        MOD_CATEGORY,
        GameRuleType.BOOL,
        BoolArgumentType.bool(),
        GameRuleTypeVisitor::visitBoolean,
        Codec.BOOL,
        b -> b ? 1 : 0,
        false,
        FeatureFlagSet.of()
    )
);
```
