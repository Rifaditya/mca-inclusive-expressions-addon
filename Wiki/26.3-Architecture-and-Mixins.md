## 5. Developer Extension Hooks

Addon developers can inspect or mutate an entity's chest genetics at runtime by casting to `GeneticsDuck`:

```java
import net.instantgratification.mcainclusive.ducks.GeneticsDuck;

if (villager.getGenetics() instanceof GeneticsDuck duck) {
    // Query independent breast sizes
    float left = duck.getLeftBreastSize();
    float right = duck.getRightBreastSize();

    // Mutate 3D Euler angles
    duck.setLeftBreastPitch(15.0f);
    duck.setRightBreastPitch(15.0f);

    // Refresh dimensions
    villager.refreshDimensions();
}
```
