## 2. Step-by-Step Player Workflow

1. **Natural Spawning**:
   - Female villagers automatically sample independent left and right chest volumes according to the Gaussian bell-curve distribution.
   - Male villagers evaluate the server GameRule `full_chested_trait_chance`. If selected, they spawn with the `Full-Chested` trait and receive standard anatomical scaling.
2. **Opening the Editor**:
   - Approach any villager while holding an **Editor Token** or executing `/mca editor` (Creative mode / Admin).
   - Click the **[ Character ]** category tab on the left panel, then select the 5th subpage tab: **[ Breast ]**.
3. **Adjusting Size & Volume**:
   - In the **[ Size ]** sub-category, drag the **Left Size** and **Right Size** sliders from `0%` to `100%`.
   - By default, **Slider Link Mode** is set to `LINKED (Symmetric)`, synchronizing both sides. Click to toggle to `UNLINKED (Asymmetric)` for individual adjustments.
4. **Positioning & Angling**:
   - Switch to **[ Position ]** to adjust horizontal ($X$), vertical ($Y$), and depth ($Z$) placement.
   - Switch to **[ Rotation ]** to adjust Pitch (tilt up/down), Yaw (cleavage angle), and Roll (sideways tilt).
5. **Enabling Anti-Back-Poke Guard**:
   - If large chest scales cause geometry to clip through the villager's back, click **Back-Face Anchor: ON**. The model will immediately clamp internal vertices against the torso wall.

## 3. Mathematical Formulas & Equations

### Gaussian Bell-Curve Volume Sampling
Breast sizes in the natural population are sampled continuously using a normal distribution truncated to $[0.0, 4.44]$:

$$X \sim \mathcal{N}(\mu, \sigma^2) \quad \text{where } \mu = 0.225, \; \sigma = 0.075, \; X \in [0.0, 4.44]$$

In Java code (`MCAInclusiveExpressionsAddon.sampleGraphBreastSize`):
```java
double gaussian = random.nextGaussian();
double pct = 0.225 + gaussian * 0.075;
float clampedPct = (float) Math.min(1.0, Math.max(0.0, pct));
return clampedPct * 4.44f;
```

### Natural Anatomical Asymmetry
Real anatomical structures exhibit slight bilateral variation. MCA Inclusive Expressions samples independent left and right scale parameters with a continuous $\pm 1\%$ variance window:

$$S_{\text{left}} = \min\left(4.44, \; \max(0.0, \; X + \Delta)\right), \quad S_{\text{right}} = \min\left(4.44, \; \max(0.0, \; X - \Delta)\right)$$

$$\Delta \sim \mathcal{U}(-0.0444, \; +0.0444)$$

### Armor Scaling Compensation
To prevent 3D armor models from intersecting or clipping into the body mesh, armor cube dimensions are proportionally rescaled:

$$S_{\text{armor}} = S_{\text{body}} \times 0.55 + 0.20$$

### Dual-Matrix Inverse Vertex Clamping
The `TorsoClippingVertexConsumer` un-transforms world-space coordinates back to the torso's local coordinate frame using the inverted torso matrix $M_{\text{torso}}^{-1}$, applies a one-sided spatial clamp at the torso back wall, and re-transforms to world coordinates:

$$P_{\text{torso}} = M_{\text{torso}}^{-1} \cdot P_{\text{world}}$$

$$P'_{\text{torso}}.z = \begin{cases} P_{\text{torso}}.z & \text{if } P_{\text{torso}}.z \le Z_{\text{wall}} \\ Z_{\text{wall}} & \text{if } P_{\text{torso}}.z > Z_{\text{wall}} \end{cases}$$

$$P_{\text{final}} = M_{\text{torso}} \cdot P'_{\text{torso}}$$

where $Z_{\text{wall}} = 1.5 / 16.0 = 0.09375\text{ blocks}$. Camera transformation prefixes cancel algebraically ($M_{\text{cam}}^{-1} \cdot M_{\text{cam}} = I$), ensuring identical behavior in world rendering and GUI screens.

## 7. Developer & Mixin Hooks

### `TorsoClippingVertexConsumer.java`
```java
// Dual-matrix relative transform clamps vertices beyond TORSO_WALL_Z
public class TorsoClippingVertexConsumer implements VertexConsumer {
    private static final float TORSO_WALL_Z = 1.5f / 16.0f;
    private final VertexConsumer delegate;
    private final Matrix4f torsoMatrix;
    private final Matrix4f torsoMatrixInverse;

    public TorsoClippingVertexConsumer(VertexConsumer delegate, Matrix4f torsoMatrix) {
        this.delegate = delegate;
        this.torsoMatrix = new Matrix4f(torsoMatrix);
        this.torsoMatrixInverse = new Matrix4f(torsoMatrix).invert();
    }

    @Override
    public VertexConsumer addVertex(float x, float y, float z) {
        Vector3f torsoPos = torsoMatrixInverse.transformPosition(x, y, z, scratch);
        if (torsoPos.z() > TORSO_WALL_Z) {
            torsoPos.set(torsoPos.x(), torsoPos.y(), TORSO_WALL_Z);
            torsoMatrix.transformPosition(torsoPos, scratch);
            return delegate.addVertex(scratch.x(), scratch.y(), scratch.z());
        }
        return delegate.addVertex(x, y, z);
    }
}
```
