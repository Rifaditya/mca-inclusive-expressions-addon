## 2. Step-by-Step Developer Build Workflow

1. **Verify JDK 25 Installation**:
   ```bash
   java -version
   # Expected output: openjdk version "25" ...
   ```
2. **Navigate to Version Subproject**:
   ```bash
   cd "MCA Inclusive Expressions Addon v26.2/mca-inclusive-expressions-addon"
   ```
3. **Execute Clean Build**:
   ```bash
   ./gradlew clean build --no-daemon
   ```
4. **Inspect Generated Artifact**:
   - The primary remapped mod JAR is created at:
     `build/libs/mca-inclusive-expressions-addon-4.5.1+26.2.jar`
   - The automated archive task automatically deploys the JAR to:
     `../../Archive Jar of all versions/MC 26.2/mca-inclusive-expressions-addon-4.5.1+26.2.jar`

## 4. `build.gradle` Toolchain & Dependencies

```groovy
dependencies {
    minecraft "com.mojang:minecraft:${project.minecraft_version}"

    implementation "net.fabricmc:fabric-loader:${project.fabric_loader_version}"
    implementation "net.fabricmc.fabric-api:fabric-api:${project.fabric_version}"

    implementation "net.dasik.social:dasik-library:${project.dasik_library_version}"

    // MCA Common / Fabric JAR reference for compilation
    compileOnly files(".../mca-fabric-8.1.4+26.2.jar")

    // Optional GUI Dependencies
    compileOnly "dev.isxander:yet-another-config-lib:3.9.5+26.2-fabric"
    compileOnly "com.terraformersmc:modmenu:18.0.0-beta.1"
}
```
